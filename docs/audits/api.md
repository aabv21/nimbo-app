Statuses as in [`security.md`](security.md): `fixed` names its test; `accepted` gives the reason and the cost; `deferred`

pinned it" (`fixed`, with the new pin) or "verified, already pinned" (`accepted`).

## Method

- **PostgREST** as two signed-in users in pgTAP (`supabase/tests/api_audit.test.sql`): user B calls every client RPC
  with user A's ids, then A's rows are compared byte for byte; every client RPC with a `jsonb` argument gets an unknown
  key; the client's table, column and function privileges are compared with fixed lists, so a new grant or function
  fails until it is reviewed.
- **The functions** through the local gateway (`integration/apiAudit.int.test.ts`): garbage, expired, wrong-key and
  anon-key bearers; a signed-out session's token; chunked bodies past each cap; a browser preflight; error bodies.
- **The source** (`supabase/functions/_shared/__tests__/logScan.test.ts`): `verify_jwt` per function, error replies,
  outbound hosts.
