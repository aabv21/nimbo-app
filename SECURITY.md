# Security policy

This repository is a portfolio demo rather than a supported product, but security reports are welcome.

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| Earlier builds | No |

## Reporting a vulnerability

Report it privately with GitHub's private vulnerability reporting: the **Report a vulnerability** button under the **Security** tab. Please don't open a public issue. Include what's affected, how to reproduce it, and the impact you expect. You'll get an answer within a week.

## Scope

The app, the database migrations and policies and the configuration in this repository. Vulnerabilities in the services it integrates with (Supabase, Apple, Google, Expo, Anthropic, TypeSafe, Open-Meteo, Brevo) belong to their own disclosure programs.
