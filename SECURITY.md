# Security policy

This repository is a portfolio demo rather than a supported product, but security reports are welcome.

## Reporting a vulnerability

Report it privately. While the repository is private, write to hello.aabv21@gmail.com; GitHub's private vulnerability reporting (the **Report a vulnerability** button under the **Security** tab) is switched on when the repository becomes public. Please don't open a public issue. Include what's affected, how to reproduce it, and the impact you expect. You'll get an answer within a week.

## Scope

The app, the database migrations and policies and the configuration in this repository. Vulnerabilities in the services it integrates with (Supabase, Apple, Google, Expo) belong to their own disclosure programs.
